# Coffee-Machine
A command-line coffee machine simulator built with Python.

# Technologies Used
Python 3

## How to Run It
1. Download the file
2. Open your terminal
3. Run: python coffee_machine.py

## Features
- Choose from different coffee types (Espresso, Latte, Cappuccino)
- Checks if resources (water, milk, coffee) are sufficient
- Handles coin/payment input
- Tracks and displays resource levels
