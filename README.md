# Coffee-Machine
A command-line coffee machine simulator built with Python.

# Technologies Used
Python 3

## How to Run It
1. Make sure you have Python 3 installed
2. Download ALL these files into the same folder:
   - coffee_machine.py
   - menu.py
   - money_machine.py
   - coffee_maker.py
3. Open your terminal in that folder
4. Run: python coffee_machine.py

## How to Use It
- Type a drink name to order (e.g. espresso, latte, cappuccino)
- Insert coins when prompted
- Type "report" to see resources and profit
- Type "off" to turn the machine off

## Features
- Choose from a menu of available drinks
- Checks if resources are sufficient before making a drink
- Accepts coin payment and validates the amount
- Prepares and serves the selected drink
- Displays a full resource and profit report (type "report")
- Machine can be turned off with a command (type "off")
